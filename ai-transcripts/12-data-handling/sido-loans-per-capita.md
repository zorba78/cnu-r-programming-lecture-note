## 응답 (원문 그대로)

````markdown
세 파일을 아래 순서로 합치면 원하는 표를 만들 수 있어요.

**처리 순서**
1. 세 CSV 불러오기
2. `loans-2026.csv`를 월별 칼럼(wide) → 한 칼럼(long)으로 변환
3. `도서관ID` 기준으로 도서관에 `시도` 정보 붙이기
4. `시도`별로 1~8월 대출권수 합산 (휴관 달의 빈칸은 0으로 취급)
5. 인구 자료를 `시도` 기준으로 결합해서 인구 1만 명당 대출권수 계산
6. 내림차순 정렬

```r
library(tidyverse)

# 1. 불러오기 ----------------------------------------------------------
libraries <- read_csv("libraries.csv")
loans     <- read_csv("loans-2026.csv")
sido_pop  <- read_csv("sido-population.csv")
# 한글이 깨져서 보이면 locale = locale(encoding = "EUC-KR") 옵션을 추가해서 다시 읽어보세요.

# 2. 대출권수 wide -> long ------------------------------------------------
loans_long <- loans |>
  pivot_longer(
    cols      = starts_with("2026"),   # "2026.01" ~ "2026.08"
    names_to  = "월",
    values_to = "대출권수"
  )
# 빈칸(휴관)은 read_csv가 자동으로 NA로 읽어들입니다.

# 3. 도서관ID로 시도 붙이기 -----------------------------------------------
loans_sido <- loans_long |>
  left_join(libraries |> select(도서관ID, 시도), by = "도서관ID")

# 조인이 제대로 됐는지 확인 (아래 결과가 0행이어야 정상)
loans_sido |> filter(is.na(시도)) |> distinct(도서관ID)

# 4. 시도별 1~8월 총 대출권수 --------------------------------------------
sido_loans <- loans_sido |>
  group_by(시도) |>
  summarise(총대출권수 = sum(대출권수, na.rm = TRUE), .groups = "drop")
# na.rm = TRUE -> 휴관한 달(NA)은 0으로 보고 합산

# 5. 인구 결합 + 인구 1만 명당 대출권수 -----------------------------------
result <- sido_loans |>
  left_join(sido_pop, by = "시도") |>
  mutate(`대출권수_1만명당` = round(총대출권수 / 인구 * 10000, 1)) |>
  arrange(desc(`대출권수_1만명당`)) |>
  select(시도, 권역, 총대출권수, 인구, `대출권수_1만명당`)

# 인구를 못 찾은 시도가 있는지 확인 (아래 결과가 0행이어야 정상)
result |> filter(is.na(인구))

print(result, n = Inf)   # 시도 개수가 10개 넘으면 잘려 보이니 n = Inf로 전체 출력
```

**꼭 확인해보면 좋은 것 세 가지**

1. **빈칸 = 0 가정**: 문제에서 "휴관한 달은 빈칸"이라고 알려줬으니 `na.rm = TRUE`로 0처럼 합산했어요. 이 가정이 맞는지(정말 0권인지, 혹시 집계 누락인 달이 섞인 건 아닌지)는 과제 맥락에서 한 번 확인해보세요.
2. **`도서관ID` 조인 확인**: `loans_sido |> filter(is.na(시도))`가 비어 있는지 꼭 확인하세요. 뭔가 나온다면 `도서관ID` 표기가 두 파일 사이에 안 맞는 겁니다.
3. **시도 이름 표기 불일치**: `sido-population.csv`는 "다른 기관"에서 받았다고 하셨으니, `libraries.csv`의 시도 표기와 정확히 일치하는지 의심해봐야 해요. 특히 강원도/강원특별자치도, 전라북도/전북특별자치도처럼 최근에 명칭이 바뀐 지역은 기관마다 다르게 쓰는 경우가 있어요. `result |> filter(is.na(인구))`에 뭔가 걸리면, `setdiff(unique(libraries$시도), unique(sido_pop$시도))`로 어떤 표기가 다른지 찾아서 맞춰주면 됩니다.

이 세 가지 확인만 통과하면 `result`가 바로 원하는 표예요 (`대출권수_1만명당` 기준 내림차순 정렬).
````
