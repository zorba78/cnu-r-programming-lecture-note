## 응답 전문 (수정 없음)

핵심부터 말하면, 이 데이터는 환자번호가 P01~P20으로 전부 다르고 약 A와 약 B가 서로 다른 환자에게 배정된 것으로 보여서, 독립 두 표본 검정(Welch t-검정)을 쓰면 돼. 앞부분만 봐서는 A가 4명뿐이라 B가 어떻게 배정됐는지는 확인하지 못했어. 만약 같은 환자가 A와 B를 모두 복용했다면(환자번호가 반복된다면) 대응표본 검정을 써야 해서, 아래 코드의 확인 단계에서 먼저 점검해 줘.

## R 코드

```r
library(readr)
library(dplyr)
library(ggplot2)

# 1. 데이터 불러오기 (한글 컬럼이라 인코딩 문제가 생기면 locale 지정)
dat <- read_csv("sleep-drug.csv")
# 한글이 깨지면: read_csv("sleep-drug.csv", locale = locale(encoding = "CP949"))

dat$약 <- factor(dat$약)

# 2. 구조 확인: 환자번호가 중복되는지(대응 설계인지) 점검
str(dat)
n_distinct(dat$환자번호)   # 20이면 환자마다 한 번씩만 측정 -> 독립 두 표본
table(dat$약)              # 각 약의 표본 크기

# 3. 기술통계
dat |>
  group_by(약) |>
  summarise(n = n(), 평균 = mean(수면증가), 표준편차 = sd(수면증가))

# 4. 시각화
ggplot(dat, aes(x = 약, y = 수면증가)) +
  geom_boxplot() +
  geom_jitter(width = 0.1)

# 5. 가정 확인
# 정규성 (표본이 작으므로 그룹별로 확인)
tapply(dat$수면증가, dat$약, shapiro.test)
# 등분산성
var.test(수면증가 ~ 약, data = dat)

# 6. 검정: Welch 독립 두 표본 t-검정 (등분산 가정 없음)
res <- t.test(수면증가 ~ 약, data = dat)
res

# 7. 비모수 대안 (정규성이 의심될 때)
wilcox.test(수면증가 ~ 약, data = dat, exact = FALSE)
```

만약 2단계에서 같은 환자가 A와 B 양쪽에 나온다면(환자번호가 10개이고 각 2번씩 등장), 아래처럼 대응표본 t-검정을 써야 해.

```r
library(tidyr)
wide <- dat |> pivot_wider(names_from = 약, values_from = 수면증가)
t.test(wide$A, wide$B, paired = TRUE)
```

## 가설

- 귀무가설 H0: 두 약의 평균 수면증가가 같다 (μA = μB)
- 대립가설 H1: 두 약의 평균 수면증가가 다르다 (μA ≠ μB), 양측검정

## 결과 해석 방법

1. 기술통계와 상자그림으로 어느 약의 평균이 더 큰지, 산포가 어떤지 먼저 본다.
2. `t.test` 출력에서 볼 것:
   - **p-value**: 유의수준 0.05보다 작으면 H0를 기각한다. 즉 "두 약의 평균 수면증가에 통계적으로 유의한 차이가 있다"고 결론 낸다. 0.05 이상이면 "차이가 있다는 충분한 증거를 얻지 못했다"고 쓴다. (같다고 증명된 것은 아니라는 점에 주의)
   - **95% 신뢰구간**: `mean in group A - mean in group B`의 구간이다. 0을 포함하지 않으면 5% 수준에서 유의하고, 구간의 부호와 크기로 차이의 방향과 크기(몇 시간 차이인지)를 해석할 수 있다.
   - **t 통계량, 자유도(df)**: 보고서에는 `t(df) = ..., p = ...` 형태로 적는다. Welch 검정은 자유도가 소수로 나오는 게 정상이다.
3. 가정 점검:
   - Shapiro-Wilk p > 0.05이면 정규성을 크게 의심하지 않아도 된다. 표본이 그룹당 10명 정도로 작으니 상자그림과 함께 판단하고, 크게 벗어나면 Wilcoxon 검정 결과를 함께 제시한다.
   - Welch 검정은 등분산이 아니어도 쓸 수 있어서 `var.test`는 참고용이다.

## 보고서 문장 예시

"약 A의 평균 수면증가는 ○○시간, 약 B는 ○○시간이었다. Welch 독립 두 표본 t-검정 결과 두 약의 평균 차이는 ○○시간(95% CI: ○○ ~ ○○)이며, 통계적으로 유의하다/유의하지 않다(t = ○○, df = ○○, p = ○○)."

표본이 작기 때문에 유의하지 않더라도 "효과가 없다"가 아니라 "검정력이 부족할 수 있다"는 점을 한 줄 덧붙이면 좋아.
