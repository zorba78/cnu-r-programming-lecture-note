# 11장 데이터 입출력 연습 파일

강의노트 11장 "데이터 입출력"에서 쓰는 파일이다. **모두 교육용 가상 자료**이며 도서관 이름, 우편번호, 수치, 설문 응답은 실제와 무관하다.

| 파일 | 형식 | 일부러 넣어 둔 함정 |
|---|---|---|
| `library-loans.csv` | CSV, **CP949** 인코딩 | 제목 줄 2개, 앞자리가 0 인 우편번호, `2004.03.15` 형태의 날짜, 따옴표 안의 천 단위 쉼표(`"48,215"`), 휴관 도서관의 `-`, 맨 아래 합계 행, 쉼표가 들어간 주석 행 |
| `survey.xlsx` | Excel | 첫 줄 제목, 날짜 열에 섞인 글자 `미정`, 만족도 `9` = 무응답 (설명은 `안내` 시트에만 있음) |
| `survey.sav` | SPSS | 같은 설문. 값 라벨과 사용자 정의 결측값(`9`)을 담고 있음 |
| `survey.csv` | CSV, UTF-8 | 같은 설문을 CSV 로 내보낸 파일. 라벨과 결측 정보가 사라지고 숫자 `9` 만 남음 |

파일을 다시 만들려면 프로젝트 폴더에서 `Rscript dataset/ch11/make-ch11-data.R` 을 실행한다.
