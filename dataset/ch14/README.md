# 14장 기초통계 분석 연습 파일

강의노트 14장 "기초통계 분석"에서 쓰는 파일이다. 이 폴더의 새 파일은 하나다.

1~7절의 다른 자료는 이 폴더에 없다. `dataset/DBP.txt`, `dataset/titanic3.csv` 는 `dataset/` 에 있고, `iris`, `mtcars`, `sleep`, `anscombe` 는 R 에, `coagulation` 은 faraway 패키지에 들어 있다. `data/dysmenorrhea.rds` 는 학생 배포용 `dataset.zip` 에 없으므로 강의노트 서두의 안내대로 내려받는다.

## `sleep-drug.csv`

| 열 | 유형 | 값 |
|---|---|---|
| `환자번호` | 문자 | `"P01"` ~ `"P10"` |
| `약` | 문자 | `"A"`, `"B"` |
| `수면증가` | 실수 | 약을 먹었을 때 평소보다 늘어난 수면 시간(시간 단위). 음수는 줄어든 시간 |

- **한 행**: 환자 한 명이 약 하나를 먹은 기록. 20행.
- **출처**: R 의 `datasets::sleep` (Cushny & Peebles, 1905 의 수면제 자료. Student, 1908 이 인용). 값은 그대로 쓰고 열 이름만 한국어로 바꾸었다.
- **가상인 부분**: 약 B 행(파일의 12~21줄)의 순서를 `set.seed(2026)` 로 섞었다. 값은 실제 자료이고 **행 순서는 가상**이다.
- **일부러 넣어 둔 함정**: 이 파일에는 자료 구조를 확인하지 않으면 틀린 검정을 고르게 되는 함정이 두 가지 있다. 강의노트 8절 "AI와 함께"에서 드러나므로 생성 스크립트는 장을 끝낸 뒤 열어 보기를 권한다.

파일을 다시 만들려면 프로젝트 폴더에서 `Rscript dataset/ch14/make-ch14-data.R` 을 실행한다. 스크립트는 끝에서 행 수, 약별 합계와 평균, 검정 결과를 출력해 강의노트의 수치와 대조할 수 있게 한다.
