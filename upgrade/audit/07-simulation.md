## A. 치명 — 코드가 본문과 다르게 동작하고, 결과가 그것을 가림

### A-1. DBP 영분포 시뮬레이션이 두 군 평균차가 아니라 40개 전체의 평균을 만듦 [재현]

**줄** 1284–1322 (특히 1301–1304, 1321)

주석(1295–1299)은 "귀무가설이 참이라는 가정 하에서 DBP 변화량의 두 군 간 차이에 대해 10,000개의 표본 생성"이라고 한다. 코드는 두 군을 나누지 않는다.

```r
delta_star <- replicate(B, rnorm(n, 0, sp))       # n = 40 개를 한 덩어리로
md_star <- apply(delta_star, 2, mean)              # 40개 전체의 평균
t_star <- md_star/(sd_star * sqrt(1/n1 + 1/n2))
```

40개 전체 평균의 SD 는 $s_p/\sqrt{40}$, 두 군 평균차의 SD 는 $s_p\sqrt{1/20 + 1/20} = s_p/\sqrt{10}$ 이다. 따라서 `t_star` 는 정확히 $T_{39}/2$ 를 따른다.

```
sd(md_star) 0.428    두 군 평균차의 이론 SD 0.856 의 절반
sd(t_star)  0.514    t(38) 의 SD 1.027 의 절반
영분포 5% 분위수      본문 -0.85  /  올바른 영분포 -1.68  /  qt(0.05, 38) -1.69
이 영분포로 단측 검정할 때의 1종 오류
  정확값 pt(qt(.05, 39)/2, 38) = 0.202,  H0 자료 5,000개 모의 0.197  (명목 0.05)
```

**무엇이 가렸나**: 관측 t = −12.15 (`t.test` p = 1.2×10⁻¹⁴) 라 영분포 폭이 절반이어도 p = 0 이 나온다. 배포본도 `[1] 0` 을 출력한다. 효과가 중간 크기인 자료에 이 코드를 재사용하면 p값이 체계적으로 너무 작게 나온다. 1318줄 `qqnorm(t_star)` 는 직선이라 확인한 것처럼 보이지만, 척도 오류는 Q-Q 그림에 드러나지 않는다.

부수 문제: 1321줄은 단측 p 인데 1203줄 `t.test()` 는 양측이고, 둘을 비교하는 문장이 없다. B = 10,000 에서 0건이면 "p = 0" 이 아니라 "p < 1/10,000" 이다.

**수정**: 반복마다 두 군을 따로 생성한다.

```r
t_star <- replicate(B, {
  a <- rnorm(n1, 0, sp); b <- rnorm(n2, 0, sp)
  (mean(a) - mean(b)) / (sqrt((var(a) + var(b)) / 2) * sqrt(1/n1 + 1/n2))
})
sd(t_star)                  # 1.018  (이론 sqrt(38/36) = 1.027)
quantile(t_star, 0.05)      # -1.681 (qt(0.05, 38) = -1.686)
```

새 9장에서는 **"먼저 귀무가설이 참인 세계에서 돌려 1종 오류가 α 인지 확인한다"** 를 시뮬레이션 코드 검증의 첫 단계로 가르친다. 이 버그가 그 확인 한 번으로 잡힌다.

### A-2. 신뢰구간 두 번째 모의실험: "귀무가설이 참일 때"라고 적고 참 차이 −1.58 인 세계를 만듦 [재현]

**줄** 1750(본문), 1754·1766–1767(코드), 1776(범례)

본문은 "독립 이표본 t 검정에서 **귀무가설이 참일 때** 두 집단 간 평균 차이에 대한 95% 신뢰구간이 0을 포함하는 빈도"를 보인다고 한다. 코드는 `m_true <- 0` 으로 두지만 표본은 `rnorm(n1, 0.75, 1.79)`, `rnorm(n2, 2.33, 2.0)` 에서 뽑는다. `sleep` 의 관측 평균을 그대로 쓴 것이라 **참 차이는 −1.58** 이다. 범례는 0 을 "true mu" 라고 부른다.

```
0 을 포함하지 않은 구간 (본문 코드, set.seed(1313))      44 / 100
참 차이 -1.58 에서 0 을 배제할 확률 = 검정력 0.422    → 약 42개 기대
두 평균을 모두 0.75 로 두면 (실제 귀무가설)           3 / 100
```

이 그림은 신뢰구간의 포함확률이 아니라 **검정력**을 보여 준다. "신뢰구간의 정확한 의미" 절에서 100개 중 44개가 빨간색으로 그려지는데 본문은 아무 설명이 없다. 절의 목적과 정반대의 인상을 준다.

**수정**: 둘 중 하나. (1) 본문대로 두 평균을 같게(예: 둘 다 0.75) 두어 약 5% 가 0 을 배제함을 보인다. (2) 코드를 살리고 본문을 "대립가설이 참일 때 0 을 배제하는 비율 = 검정력"으로 고친다. 새 9장에서는 **둘을 나란히** 두어 "같은 코드, 참값만 다르다"를 대조하는 편이 낫다(1종 오류·검정력 절로 연결).

### A-3. `sleep` 은 쌍체 자료인데 독립 이표본 t 검정 — α = 0.05 에서 결론이 뒤집힘 [재현]

**줄** 1669(본문 "10명의 대상자가 수면제 1과 수면제 2를 복용"), 1674, 1687, 1694, 1703–1710, 1714–1779

`sleep` 은 10명의 `ID` 가 두 군에 한 번씩 나오는 쌍체 자료다(`table(sleep$ID, sleep$group)` 의 모든 칸이 1). 본문 스스로 "10명이 두 약을 복용"이라 적고 곧바로 20명짜리 독립 이표본 검정(df = 18)을 한다.

```
독립(등분산)  t = -1.861, p = 0.0792, 95% CI (-3.364, 0.204)    ← 본문
쌍체          t = -4.062, p = 0.0028, 95% CI (-2.460, -0.700)
```

1709–1710줄 `# check` 는 `t.test()` 와 수기 계산이 일치하는지 확인한다. 이는 **산술의 검증이지 모형 선택의 검증이 아니다**. "코드가 맞게 계산했다"와 "맞는 분석을 했다"가 다른 질문임을 보여 주는 사례로 쓸 수 있다.

**수정**: 이 절의 목적이 독립 이표본 신뢰구간이라면 독립 배정 자료로 바꾼다(같은 장의 DBP A/B 군, 20 대 20 무작위 배정). `sleep` 을 남긴다면 쌍체로 분석한다. R 4.4 이후 `t.test(extra ~ group, data = sleep, paired = TRUE)` 는 `cannot use 'paired' in formula method` 오류가 난다(R 4.6.1 재현). 다음 형태를 쓴다.

```r
sleep_wide <- reshape(sleep, direction = "wide", idvar = "ID", timevar = "group")
t.test(Pair(extra.1, extra.2) ~ 1, data = sleep_wide)    # t = -4.062, p = 0.00283
```

같은 분석이 `12-basic-stat-analysis.Rmd:1405` 에도 있다(F 절).

### G-3. 검증 활동 (6장과 상호참조)

1. **추정값 ± 2SE**: 모든 시뮬레이션 결과를 이 형태로 보고하고 이론값이 그 안에 드는지 확인한다. 테스트로 쓰면 `expect_lt(abs(est - theory), 4 * se)`.
2. **보정 확인(calibration)**: 검정·신뢰구간 코드는 귀무가설이 참인 세계에서 먼저 돌려 1종 오류율·포함률이 명목값인지 확인한다. A-1, A-2 가 이 확인 한 번으로 잡힌다.
3. **정확값이 있는 문제로 먼저 검증**: 13장 카드($1-1/e$), 적분(`integrate()`), 검정력(`power.t.test()`)으로 코드를 검증한 뒤 정확값이 없는 문제에 쓴다.
4. **대안 구현 대조**: 루프와 벡터 구현이 같은 시드에서 `identical()` 인지 확인한다(13장 카드, 적중법 모두 TRUE 로 재현됨).
5. **값을 반환하는 함수**: `cat()` 만 하는 함수(B-18)는 테스트할 수 없다. 6장 `testthat` 절과 연결한다.

## I. 이 감사가 남긴 교재

8장 감사의 A-2(시드가 이진 탐색 버그를 가림)와 짝을 이루는 사례가 이 장에서 나왔다.

- **A-1** 은 6장·9장의 대표 교재가 된다. "p = 0 이 나왔으니 코드가 맞다"는 착각을 정확히 보여 준다. 영분포 폭이 절반인데 관측값이 극단적이라 결론이 우연히 맞았고, 귀무가설 하에서 한 번 돌리면 1종 오류 20% 가 드러난다.
- **A-2** 는 "출력을 읽는 습관"의 사례다. 오류가 그림에 그대로 보였는데(100개 중 44개가 빨간색) 본문은 해석하지 않았다.
- **A-3** 은 "계산의 검증"과 "모형의 검증"이 다르다는 사례다. `# check` 로 수기 계산과 `t.test()` 가 일치함을 확인했지만 분석 설계 자체가 틀렸다.
- **B-16** 은 경계 사례(부호) 테스트를 가르친다. `2*pt(tval)` 은 입력의 절반(양수 t)에서 확률 1을 넘는다.
