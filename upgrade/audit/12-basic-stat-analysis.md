## A. 치명 — 분석 또는 핵심 식이 틀림

### A-1. 쌍체 자료 `sleep` 을 독립 이표본 t 검정으로 분석 [재현]

**줄** 1401–1412 (주석 1402 "독립이표본 t 검정 결과", 1405 `t.test(extra ~ group, data = sleep, var.equal = TRUE)`), 1440 `tidy(t1)`

`table(sleep$ID, sleep$group)` 의 모든 칸이 1이다. 10명이 두 군에 한 번씩 나온다.

```
독립(등분산)  t = -1.861, df = 18, p = 0.0792, 95% CI (-3.364, 0.204)   ← 본문
쌍체          t = -4.062, df = 9,  p = 0.0028, 95% CI (-2.460, -0.700)
```

이 절의 목적은 "검정 결과를 데이터 프레임으로 꺼내기"라서 자료 구조를 아무도 보지 않는다. 쌍체 설계를 독립으로 분석하면 개인차가 오차에 섞여 검정력을 잃는다. 개인차 SD 2, 효과 1, n = 10 인 모의 자료(4,000회)에서 독립 분석의 검정력은 0.042, 쌍체 분석은 0.514 다.

**수정**: (1) 이 절의 예제를 독립 배정 자료로 바꾼다(같은 장의 `dysmenorrhea` pdi 가 이미 있다). (2) `sleep` 은 대응 표본 절로 옮겨 쌍체로 분석한다. R 4.4 이후 `t.test(extra ~ group, data = sleep, paired = TRUE)` 는 `cannot use 'paired' in formula method` 오류다(R 4.6.1 재현). 다음 둘 중 하나를 쓴다.

```r
sleep_wide <- reshape(sleep, direction = "wide", idvar = "ID", timevar = "group")
t.test(Pair(extra.1, extra.2) ~ 1, data = sleep_wide)              # t = -4.062, p = 0.00283
with(sleep_wide, t.test(extra.1, extra.2, paired = TRUE))           # 같은 결과
```

### A-2. 집단 내 제곱합 식 $SSW = \sum n_i s_i^2$ — 변동분해 항등식이 성립하지 않음 [재현]

**줄** 903, 909 (정의 856: $s_i^2 = \frac{1}{n_i-1}\sum(\cdot)^2$)

$\sum_j (y_{ij} - \bar y_{i.})^2 = (n_i - 1)s_i^2$ 이므로 $SSW = \sum_i (n_i - 1) s_i^2$ 다. `faraway::coagulation` 으로 계산하면 다음과 같다.

```
anova() 의 SSW 112      sum((n_i - 1) s_i^2) 112      본문 sum(n_i s_i^2) 132.99
SST 340                 SSB + 본문 SSW = 360.99  (항등식 불성립)
```

909줄의 식은 이 소절("분산분석의 변동분해 과정")의 결론이다. `plot_anova_sim()`(997–1003)은 정의대로 계산해 출력은 맞으므로 배포본에서는 드러나지 않는다. 학생이 식대로 손으로 계산하면 F 값이 틀린다.

**수정**: 903, 909 의 $n_i s_i^2$ → $(n_i - 1) s_i^2$.

## F. 다른 장과의 관계

1. **새 9장과 겹치는 내용** — 9장이 이미 다룬다. 14장은 참조만 한다.
   - 신뢰구간의 의미 @sec-ci-meaning, 1종 오류와 p값 분포 @sec-type1-error, 검정력과 `power.t.test()` @sec-power
   - 등분산 가정이 깨질 때 Student 대 Welch 의 1종 오류, `t.test()` 기본값이 Welch 인 이유, 로그정규 자료의 신뢰구간 @sec-assumption
   - 몬테카를로 오차(추정값 ± 2SE) @sec-monte-carlo, 시드 @sec-random-seed
   - 9장에 **없는** 것(14장 몫): 대응 표본, Q-Q plot, 분산분석, 다중비교와 사후검정, 정규성 검정의 검정력, 결과 정리(broom). 14장이 쓸 모의실험(쌍별 t 의 가족오류율, F 검정의 1종 오류, Shapiro 검정력과 n, 쌍체 대 독립 검정력)은 9장의 도구를 그대로 쓴다.
2. **새 8장** @sec-nr-regression 이 `mtcars` 로 설계행렬 $X$ 와 정규방정식을 다룬다. 14장의 "t 검정과 분산분석은 선형모형" 콜아웃(421–477)을 `model.matrix()` 로 이어 붙일 수 있다(B-8).
3. **새 12장** @sec-reframe, @sec-summarise-by 가 `reframe()` 과 `.by` 를 다룬다. 14장의 여러 변수 검정 정리는 그 위에 `broom::tidy()` 만 얹는다.
4. **현행 7장 감사**의 "기초통계 복습(DBP, 용어) → 14장으로 이동" 제안(G-1)이 아직 처리되지 않았다. 새 9장은 이 부분을 싣지 않았다. 귀무가설·대립가설·1종·2종 오류·p값 용어 정리가 새 책 어디에도 없는지 확인이 필요하다. 7장 B-10(p값과 α 혼동 문장)을 옮기지 않는다.
5. **같은 오류의 반복**: `sleep` 독립 분석(7장 A-3 ↔ 12장 A-1), `2*pt(t)` 부호(7장 B-16 ↔ 12장 B-2). 두 장 모두 같은 저자 코드에서 같은 방식으로 가려졌다.

### H-5. "AI 가 고른 검정을 검증하는 절" 후보

ID 제안 `sec-ai-basic-stat`. 응답은 `student-ai` 로 실제로 받아 `ai-transcripts/14-basic-stat-analysis/` 에 기록한다(규칙 7). 아래 "흔한 오류"는 **실제 응답에서 확인된 것만** 싣는다.

- **후보 1 (권장)**: "수면제 두 종류의 효과(추가 수면 시간)에 차이가 있는지 R 로 검정해 줘" + `sleep` 의 열 설명. 자료가 쌍체라는 사실은 명세에 쓰지 않고 `ID` 열만 보이게 한다.
  - 검증: (1) 자료 구조 `table(ID, group)` → 1절 표와 대조, (2) 코드를 실행해 R 4.4 이후 `t.test(y ~ g, paired = TRUE)` 오류 여부 확인, (3) 쌍체·독립 두 결과와 `lm(차이 ~ 1)` 대조, (4) 해석 문장 점검("유의하지 않으므로 효과가 없다" 류).
- **후보 2**: "네 가지 먹이에 따른 혈액 응고 시간을 비교하고 어떤 먹이끼리 다른지 알려 줘"(coagulation).
  - 검증: 쌍별 t 검정 6개를 보정 없이 하는지(가족오류율 모의로 대조), 집단별 Shapiro(n = 4)로 정규성을 판단하는지(검정력 0.13), Levene 의 중심값, 사후검정 이름과 결과를 `TukeyHSD()` 와 대조.
- **후보 3**: AI 가 쓴 t 검정 함수를 `t.test()` 와 원소별로 대조(B-1·B-2 와 같은 구조의 결함이 있는지).

### H-6. 새로 필요한 검증 절차

1. **자료 구조 먼저**: 같은 대상이 반복되는가(ID 반복), 반응·설명 변수의 유형, 집단 수 → 검정 선택. A-1·B-15 가 이 확인 한 번으로 잡힌다.
2. **세 경로 대조** (현 장의 장점, 유지): 수기 계산 / 내장 함수 / `lm()`. 단 이것은 계산의 검증이고 설계의 검증은 1번이 맡는다는 점을 본문에 적는다.
3. **귀무가설 하 모의실험**: F 검정의 기각률이 0.05 ± 2SE 인지, 쌍별 t 검정의 가족오류율이 얼마인지(9장 도구). B-7 이 이것으로 잡힌다.
4. **함수의 경계·부호 테스트**: `expect_equal(my_quantile(x, p), quantile(x, p, type = 5))` 를 p 격자(끝점 포함)로, 직접 만든 t 검정은 집단 순서를 바꿔서도 `t.test()` 와 비교. B-1~B-3 이 잡힌다(6장 `testthat` 과 상호참조).
5. **가정 확인은 그림 + 표본 크기**: 잔차 Q-Q, 집단별 SD 의 비. 정규성·등분산 검정의 p값만으로 결정하지 않는다(B-11).
6. **결과 표의 이름표는 이름으로 결합**하고, p값은 `format.pval()` 로 표기한다(C-10, C-11).
