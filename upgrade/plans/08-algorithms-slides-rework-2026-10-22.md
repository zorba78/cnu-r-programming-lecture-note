## 압축하거나 대본으로 옮긴 비용 내용

- 2절: 옛 "재귀의 비용" 의 반복문 글머리표 셋(공간 O(1), 깊이 제한 없음, 누적 변수)은 `iterative_sum()` 코드 주석과 대본으로, 강조 상자(점화식을 옮기는 대신 호출 깊이만큼 메모리, 5000 에 가까우면 반복문)는 왼쪽 글머리표 셋째 줄과 대본으로 옮겼다. 하노이 탑 2ⁿ − 1 과 64개 5천억 년은 함수 슬라이드 강조 상자에 남겼다(MathJax 를 유니코드로 바꿔 첨자 14px 제거).
- 3절: 옛 3.1–3.2 슬라이드의 라벨 "O(n)", "O(log n)", "최악의 경우 n 회 비교", 대본의 log₂ n 유도는 3.4 강조 상자 한 줄과 대본으로, 선형 탐색의 최악의 경우는 3.1 대본으로 옮겼다. 3.4 의 표와 정렬 비용 상자는 그대로다.

## 노트와 어긋나게 된 곳 (노트는 고치지 않음)

1. 2.1: 슬라이드는 재귀 함수를 "종료 조건, 한 단계 작게, 결과 합치기" 세 단계로 쓴다. 노트 @sec-recursion-structure 는 "종료 조건, 재귀 단계" 두 부분이다.
2. 2.1: 호출과 반환을 찍는 `sum_trace()` 는 노트에 없다.
3. 2.3: 4! 손 추적, `sapply(0:10, ...)` 와 `factorial(0:10)` 대조, 경계 입력 n = −1 은 노트에 없다(노트는 10 하나만 대조).
4. 2.4: 원판 3개의 기둥 상태 표와 함수 설계 표는 노트에 없다. 노트의 `count_moves()` 표(원판 3~6)는 슬라이드에 없다(이전 판 슬라이드에도 없었음).
5. 2.2 비용 슬라이드가 2.4 뒤에 있어, 호출 2 에서 번호를 `[2.2–2.4]` 구간으로 바꿨다.
6. 3.1~3.2: 손 추적용 길이 8 벡터 `v8 = c(3, 8, 15, 21, 30, 42, 57, 64)` 와 `u8`(21, 64 교환)은 노트에 없다. 노트는 길이 20 인 `x` 만 쓴다.
7. 3.2: 슬라이드의 `binary_search()` 는 `if` 두 줄과 `else` 형태이고 디버그용 인수 `verbose` 가 있다. 노트는 `if / else if / else` 블록 형태이고 `verbose` 가 없다. 반환값은 같다.
8. 3.1: 빈 벡터 경계(`seq_along()` 대 `1:length()`)와 3.2 의 정렬 조건 위반 시연은 노트에 없다.
9. 3.3: 슬라이드는 `sapply()` 로 전수 검사하고 못 찾은 위치와 첫 원소의 호출 기록 표를 보인다. 노트는 `vapply()` 와 `data.frame(index, target, returned)` 전체 출력이다. 경계 사례 세 개(빈 벡터, 길이 1, 없는 값)는 노트에 101 하나만 있다.

노트의 `newton_raphson()`(`deriv()` 로 도함수, `range` 로 자르기, |f(x)| 기준) 대신, 지시문대로 입력이 f, 도함수, 초기값, 허용 오차, 최대 반복인 `newton(f, fp, x0, tol, max_iter)` 을 새로 설계했다. 갱신량을 `solve(fp(x), f(x))` 로 계산해 같은 함수를 극값(f′, f″), 회귀(∇S, H), 로지스틱(∇ℓ, H)에 그대로 다시 쓴다. 반환값은 해, 반복 횟수, 반복 기록 `path`.

## 의사코드 표기 규약 (덱 전체)

- 코드 블록은 ```` ```text ````, 라벨은 `[의사코드]{.label}`. 렌더하면 `<pre class="text">` 라 테마의 출력 상자 모양(미색 바탕, 회색 띠)이고 글자는 17px, `{.dense}` 면 15px.
- 첫 줄 `function 이름(입력)`, 다음 두 줄은 네 칸 들여 `입력: …`, `출력: …`, 그다음 본문.
- 본문 줄 앞 네 칸에 자연어 절차 번호(`1.  `). 번호는 들여쓰기 깊이와 관계없이 맨 왼쪽에 둔다. 입력, 출력, else 줄은 번호 없이 들여쓰기만.

## 강사 확인 필요 (호출 3)

9. 의사코드 표기: 비교를 `=`(R 은 `==`), 대입을 `←` 로 정했다. R 의 `==` 와 다른 것을 대본에서 짚는다. `==` 로 통일하는 편이 낫다면 2, 3절 다섯 개와 틀 소개를 고친다.
10. `text` 블록이 테마의 출력 상자 모양(미색 바탕, 회색 띠)으로 그려진다. R 코드(흰 바탕, 청록 띠)와 구별은 되지만 출력과 비슷해 보인다. 의사코드 전용 모양이 필요하면 테마에 `.reveal pre.text` 를 따로 두어야 한다(네 덱 공용이라 손대지 않음).
11. 재귀 틀의 이름을 "세 단계"에서 "세 부분"으로 바꿨다. 4.3 의 `merge_sort()` 슬라이드("2절의 세 단계로 설계")는 호출 4 에서 맞춘다.
12. 2.1 의사코드 1번 줄은 R 코드(`return(n)`)에 맞춰 `return n` 으로 썼다. 자연어는 "답은 n, 곧 1".
