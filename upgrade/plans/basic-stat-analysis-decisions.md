강사 지시 (2026-10-16): "데이터 시각화 및 기초통계 분석 강의노트 업데이트 및 발표 슬라이드 생성. 노트 및 발표 슬라이드 모두에서 추상적인 표현은 하지 말 것." 작업 규칙 11(멋 부린 표현 금지)은 이 장의 모든 산출물에서 반려 사유다.

## 오케스트레이터가 정한 가정

- 장 번호와 제목은 재구성안 5절 표를 따른다: 새 14장 기초통계 분석, 출처 현행 `12-basic-stat-analysis.Rmd`.

- 감사(1단계)의 강사 확인 9건에 대해 설계 단계는 다음 가정으로 진행한다. 강사가 다르게 정하면 설계서와 원고를 고친다.
  1. 현 12장 핫픽스는 하지 않는다(8·9장과 같이 새 장 공개로 갈음). 치명 2건은 새 장의 예측·버그 찾기 문항으로 쓴다.
  2. 범주형 검정(χ², Fisher)과 상관분석은 짧은 절 하나로 넣는다(현 장 첫머리가 약속한 범위).
  3. `figures/sats-flowchart.jpg` 는 싣지 않고 구조만 한국어 표로 다시 만든다.
  4. `data/dysmenorrhea.rds` 는 `dataset/ch14/` 로 복사하지 않고 기존 경로를 그대로 참조한다. `mmpscr` 의 군 간 검정은 싣지 않는다.
  5. DBP 의 B 군은 위약군으로 본다(현행 7장 서술).
  6. 사후검정은 Tukey 를 본문으로 하고 Bonferroni 임계값 비교를 한 소절로 둔다. Scheffé 는 표에서 한 줄, Duncan 은 뺀다.
  7. 기저 특성표는 관행대로 보정하지 않되, Holm 보정 결과를 한 줄 대조해 다중성 문제를 알린다.
  8. abalone 예제는 뺀다.
  9. 기초통계 용어(귀무가설, 1종 오류, p 값, 신뢰구간)는 14장 1절에서 새 9장의 해당 절을 가리키며 한 표로 정리한다.

## 강사 확인 항목

(워커가 단계마다 덧붙인다)

### 1단계 감사 (2026-10-16, `upgrade/audit/12-basic-stat-analysis.md`)

1. **현 12장 핫픽스 여부.** 새 14장으로 대체되기 전까지 공개 사이트에 치명 2건이 남는다: `sleep` 쌍체 자료를 독립 이표본으로 분석(1405, p 0.079 대 쌍체 0.0028), $SSW = \sum n_i s_i^2$ 식 오류(903, 909). 함께 고칠 후보는 사후검정 콜아웃(B-13), $_3\mathrm{C}_2 = 6$(B-7), Case 3-b 캡션 σ²(B-10). 지금 고칠지, 새 장 공개로 갈음할지.
2. **범주형 검정과 상관분석의 포함 여부.** 현 장 첫머리 Sketch 가 $\chi^2$·Fisher 정확검정·Pearson 상관을 약속하지만 본문에는 주석 처리된 제목만 있다(B-14). 재구성안의 처리는 "유지"다. 새 14장에 넣을지, 목록에서 뺄지.
3. **`figures/sats-flowchart.jpg` 의 출처와 이용 허락.** 영문 만화 흐름도이고 출처 표기가 없다. 비표준 용어("Pearson's Regression", "Internally Normalised")도 있다. 구조만 살려 한국어 표로 다시 그리는 안을 제안했다.
4. **`data/dysmenorrhea.rds` 공개 범위.** 본문이 "임상연구에서 수집한 데이터의 일부"라고 밝힌 실제 자료다(47명, id 는 1~47 일련번호, 이름 없음). 학생 배포(`dataset/ch14/`)에 넣어도 되는지. 또 `mmpscr`(MMP score)가 월경통 군을 정하는 변수인지 — 그렇다면 이 변수의 군 간 t 검정(p = 1.8×10⁻¹⁴)은 순환이다.
5. **DBP 의 B 군이 위약군인지.** 현행 7장(1094)은 위약군이라고 적었다. 확인되면 새 14장 대응 표본 절에서 "위약군도 떨어진다(−1.55, p = 0.0012)"를 예측 문항으로 쓴다.
6. **사후검정의 범위.** Tukey 만 / Bonferroni·Scheffé 와 임계값 비교까지 / Duncan 은 R 기본에 없어 제외. 감사는 "Tukey + Bonferroni·Scheffé 임계값 표"를 제안했다.
7. **기저 특성표(여러 변수 t 검정)의 다중성.** 관행상 보정하지 않는 표인데, 같은 장에서 다중검정 문제를 가르친다. pdi 는 Holm 보정 시 p 0.0098 → 0.088. 본문에서 이 차이를 다룰지.
8. **abalone 예제.** 렌더마다 UCI 에서 내려받고 변수명이 V2~V9 이며 n = 4,177 이라 모든 p 가 0 에 가깝다. 빼거나, 로컬 사본과 효과 크기(η²)를 붙여 "n 이 크면 p 는 작아진다" 용도로만 남길지.
9. **기초통계 용어 정리의 자리.** 현행 7장 감사가 "기초통계 복습(DBP, 귀무가설·1종 오류·p값 용어) → 14장으로 이동"을 제안했으나 새 9장에는 실리지 않았다. 새 14장 1절에 둘지.

### 3단계 집필 (2026-10-16, 묶음 3: 4절 분산분석의 원리, 5절 분산분석 사례와 다중비교)

1. **5.5 가족오류율 시뮬레이션의 방식.** `TukeyHSD()` 를 5,000번 부르는 대신, 귀무가설 자료마다 여섯 쌍의 |t| 가운데 최댓값을 구해 네 임계값(Scheffé, Bonferroni, Tukey, 보정 없음)과 비교했다. 같은 판정(Tukey 는 스튜던트화 범위 기준과 같고, Bonferroni·보정 없음은 합동분산 t 와 같다)이면서 렌더가 30초 빨라지고, 임계값 표와 바로 이어진다. 결과: Scheffé 0.033, Bonferroni 0.040, Tukey 0.051, 보정 없음 0.193.
2. **경우 3-a·3-b 그림.** 이전 판 함수의 두 칸(이론 밀도와 관측 자료) 가운데 관측 자료 칸만 남겨 두 경우를 나란히 그렸다(`plot_anova_data()`). 이론 밀도 그림은 뺐다.
3. **5.2 잔차 lineup 의 결과.** 잔차 Q-Q 는 정수 초 기록 때문에 계단 모양이라 아홉 그림 가운데서 골라낼 수 있다. 본문에 "계단은 기록 단위 때문이고, 계단의 양 끝은 직선을 따른다"로 적었다. lineup 이 '골라낼 수 없음'으로 끝나지 않는 예라 슬라이드에서 설명이 필요하다.
4. **사후검정 권고 문장.** 5.5 끝에 "모든 쌍을 비교할 때는 Tukey, 미리 정한 몇 쌍만 비교할 때는 Bonferroni"를 적었다. 이 장의 권고로 둘지.
5. **분량.** 4절 347줄(설계 360), 5절 228줄(설계 275), 합 575줄(설계 635, 상한 700). 빈 줄은 3절과 같이 한 줄씩이다.

### 3단계 집필 (2026-10-16, 묶음 4: 6절 범주형 자료와 상관, 7절 결과를 표로 정리하기)

### 4단계 AI 절과 연습문제 (2026-10-16, 중단 작업 재개)

1. **응답을 재생성하지 않음.** 이전 Claude 작업의 `ai-14-sleep-drug-test.md`에 남은 Claude Sonnet 5.5 응답을 `ai-transcripts/14-basic-stat-analysis/sleep-drug-test.md`에 그대로 보존했다. 설계 6.3의 학생 프롬프트도 전문을 옮겼다. 원래 기록에 없는 시스템 지시문은 실제 호출문처럼 재구성하지 않았다.
2. **실제 응답에서 확인한 문제와 통과 항목.** 첫 설명의 P01~P20 추정은 근거가 없고, 첫 코드는 환자 수 확인 후에도 Welch를 실행한다. 그러나 응답은 반복 환자가 있으면 대응 검정을 쓰라고 명시하고, `pivot_wider()`로 환자번호에 맞춰 두 벡터를 넘기는 올바른 대안도 제공했다. 위치로 짝짓기와 formula+paired 오류는 이 응답에 없으므로 결함으로 기록하지 않았다. 대응 분석에서 차이의 정규성을 확인하는 부분은 보완했다.
3. **실행 방식.** 설계 6.3의 '경로를 바꾼 생성 코드를 실행' 대신 워커와 ai-curriculum 규칙에 따라 생성 코드 두 청크를 원문 그대로 `eval: false`로 보존했다. 별도 검증 청크가 `knitr::knit_code`에서 코드를 읽고 파일 경로만 바꾸어 실행한다. 재현 가능한 점 배치를 위해 실행 전에 시드를 지정한다. 실시간 API 호출은 없다.
4. **행 섞기 대조.** `pivot_wider()`는 자료에서 처음 만난 약 순서에 따라 열 순서도 바꾸므로 `select(환자번호, A, B)`와 `arrange(환자번호)`를 모두 거친 뒤 표를 대조했다. 값은 변하지 않아도 열 순서가 달라지는 경우를 데이터 차이로 오판하지 않도록 본문에 설명했다.
5. **연습문제 13 확정.** 실제 응답에서 확인된 '환자 수 확인과 검정 실행의 분리'를 수정하는 문항으로 정했다. 환자×약 키 중복, 짝 누락, 결측값을 확인하고 대응 구조를 확인한 뒤 검정을 실행하도록 요구한다. 마지막 연습문제는 읽기 8개와 쓰기 6개로 구성했다. 추가 강사 결정 없이 기존 설계대로 진행했다.
