## 1. 학습 목표

- Q-Q plot 으로 자료나 잔차의 분포가 정규분포와 어떻게 다른지 읽고, 정규성 검정의 p값을 **표본 크기와 함께** 해석할 수 있다.

- AI 가 고른 검정이 자료 구조에 맞는지, 생성된 코드가 짝을 올바르게 맞추는지 확인할 수 있다.

### 3.1 절 1: 검정을 고르기 전에 `{#sec-test-choice}` (약 180줄)

의도: 검정 이름보다 자료 구조를 먼저 본다. 이 절의 표가 장 전체와 8절 검증의 기준이 된다.

| 소절 | ID | PRIMM | 자료 | 줄 |
|---|---|---|---|---:|
| 같은 사람을 두 번 쟀는가 | `{#sec-paired-or-independent}` | 학원 전후 점수 표와 두 반 점수 표는 모두 "구분"·"점수" 두 열에 20행이다. 어느 표의 두 집단에 짝이 있는가? 무엇을 보면 아는가? | 손으로 만든 10명 × 2 표 두 개(`tibble`, 시드 고정) | 70 |
| 기초통계 용어 다시 보기 | `{#sec-stat-terms}` | p값이 0.03 이면 귀무가설이 참일 확률이 3% 인가? (9장에서 확인한 답을 다시 묻는 문항) | 없음(표) | 55 |
| 자료 구조로 검정 고르기 | `{#sec-choose-test}` | 다음 세 질문에 쓸 검정은? (가) 시험약 군과 위약군의 4개월 뒤 혈압 변화 비교, (나) 객실 등급별 생존 여부, (다) 네 먹이의 혈액 응고 시간 | 없음(표) | 55 |

내용:

- **1.1**: 두 표를 보여 주고 예측 → 표에 학생 번호 열을 붙이면 앞의 표는 번호가 두 번씩 나온다(`count(번호)`). 개인차를 수치로: 전후 점수 각각의 표준편차와 전후 **차이**의 표준편차를 나란히 출력한다. 정의(대응 표본, 독립 표본)는 이 뒤에 둔다. 3.1(대응 표본 t 검정)과 3.3(`sleep`)을 예고한다.
- **1.2**: 용어 표 한 개. 열은 `용어 | 이 장에서 쓰는 뜻(한 줄) | 시뮬레이션으로 확인한 곳`. 행: 모집단과 표본, 귀무가설과 대립가설, 검정통계량, 유의수준 α, p값, 1종 오류, 2종 오류와 검정력, 신뢰구간, 자유도, 효과 크기. 셋째 열은 9장 상대 링크(아래 10절 규칙): `09-simulation.html#sec-ci-meaning`, `#sec-type1-error`, `#sec-power`, `#sec-assumption`, `#sec-clt`. p값 정의 문장은 9장의 정의와 같게 쓴다. 이전 판 7장 B-10(p값과 α 혼동)을 옮기지 않는다.
- **1.3**: 관찰 대 실험(요인, 수준, 무작위 배정, 이전 판 480–489)을 다섯 줄로. 이어서 한국어 검정 선택 표(이전 판 흐름도 `figures/sats-flowchart.jpg` 의 **구조만** 가져온다, 결정 3):

| 반응 변수 | 설명 변수 | 관측의 짝 | 검정 | R 함수 | 이 장 |
|---|---|---|---|---|---|
| 연속 | 없음(기준값과 비교) | 해당 없음 | 일표본 t 검정 | `t.test(x, mu = )` | 3.1 |
| 연속 | 두 시점 또는 두 처리, 같은 대상 | 대응 | 대응 표본 t 검정 | `t.test(x, y, paired = TRUE)` | 3.1, 3.3 |
| 연속 | 범주 2개, 다른 대상 | 독립 | 독립 이표본 t 검정 | `t.test(y ~ g)` (기본 Welch) | 3.4 |
| 연속 | 범주 3개 이상, 다른 대상 | 독립 | 일원배치 분산분석 → 사후검정 | `aov()`, `anova(lm())`, `TukeyHSD()` | 4, 5 |
| 범주 | 범주 | 독립 | 카이제곱 독립성 검정, Fisher 정확검정 | `chisq.test()`, `fisher.test()` | 6.1, 6.2 |
| 연속 | 연속 | 해당 없음 | 상관계수 검정 | `cor.test()` | 6.3 |

  표 아래 두 줄: 정규성 가정이 의심될 때 쓰는 순위 기반 검정의 이름과 함수(`wilcox.test()`, `kruskal.test()`)만 적고 이 장에서는 다루지 않는다. 이원배치·반복측정 분산분석은 범위 밖, 반응이 0/1 인 회귀는 8장 로지스틱 회귀(`08-algorithms.html#sec-nr-logistic`).
  예측 (가)~(다)의 답을 표로 확인한다. (가)는 군 안의 전후 변화가 아니라 **변화량의 군 간 비교**라는 점을 3.2 에서 다룬다고 예고한다.

### 3.2 절 2: 분포 확인: 분위수와 Q-Q plot `{#sec-quantile-qq}` (약 365줄)

의도: Q-Q plot 을 직접 만들어 읽는 법을 익히고, 작은 표본에서 그림과 검정이 얼마나 흔들리는지 확인한다. 5.2(잔차로 가정 확인)와 8절(차이의 정규성)의 기준이 된다.

| 소절 | ID | PRIMM | 자료 | 줄 |
|---|---|---|---|---:|
| 분위수 | `{#sec-sample-quantile}` | `quantile(1:10, 0.25)` 는 3 인가 3.25 인가? | `1:10` | 70 |
| 분위수 함수 직접 만들기 | `{#sec-my-quantile}` | 이전 판 `my_quantile()` 은 5%·95% 에서 `quantile(type = 5)` 와 같다. `probs = c(0.001, 0.5, 0.999)` 에서도 같을까? | `rnorm(373)`, `set.seed(10)` [이전 판] | 70 |
| Q-Q plot 직접 그리기 | `{#sec-qq-manual}` | 직접 그린 Q-Q plot 의 x 축과 y 축에 놓이는 값은 각각 무엇인가? 자료가 정규분포를 따르면 점은 어디에 놓이는가? | `rnorm(500, 65, 20)`, `set.seed(1234)` [이전 판], 손그림 2장 [이전 판] | 80 |
| Q-Q plot 의 네 가지 모양 | `{#sec-qq-shapes}` | 이름을 가린 Q-Q plot (가)~(라) 가운데 꼬리가 정규분포보다 두꺼운 것과 오른쪽으로 치우친 것은? | U(−2, 2), t(8), Exp(3), Beta(4, 1) 각 10,000개, `set.seed(100)` [이전 판] | 65 |
| 표본이 작을 때와 정규성 검정 | `{#sec-normality-check}` | 정규분포에서 뽑은 표본 20개의 Q-Q plot 아홉 개 가운데 하나만 지수분포에서 뽑았다. 찾을 수 있는가? | 시뮬레이션, `iris` [이전 판] | 80 |

내용:

- **2.1**: 일상 예(키 순서 줄) → 정의(누적분포함수의 역함수, 표본 분위수는 순서통계량의 가중평균, $X_{(1)} \le \cdots \le X_{(n)}$). 2-, 4-(사분위수, IQR), 100-분위수만 예로 둔다(이전 판 목록의 오기 66.6%·"10 등분" 은 옮기지 않는다, C-3). `quantile()` 의 9가지 방법: **방법 1~3 은 계단 함수, 4~9 는 순서통계량 사이를 선형 보간**(B-4 수정). **기본값은 type 7** 이고 이전 판 식 $Q(p) = (1-\gamma)x_{(k)} + \gamma x_{(k+1)}$ 은 type 5 다. 예측 답: type 7 은 3.25, type 5 는 3.
- **2.2**: 이전 판 코드를 **그대로** 싣고(116–131) 5%·95% 대조 → 예측 → 실행: 재활용 경고와 함께 `0.046, NA, 0.045` (정답 −2.437, 0.044, 2.644). 이름표도 `0.0 %`, `100.0 %` 로 찍힌다. 조사: `which.max(pk[pk <= pj])` 가 빈 벡터에서 `integer(0)` 을 돌려 색인이 한 칸씩 밀린다. 수정: $j = \lfloor np + 0.5 \rfloor$ 를 직접 계산하고 $j < 1$ 이면 $x_{(1)}$, $j \ge n$ 이면 $x_{(n)}$. 확인: `p <- seq(0, 1, by = 0.0005)` 격자에서 `all.equal(unname(my_quantile(x, p)), unname(quantile(x, p, type = 5)))` 가 TRUE, n = 1, 2, 5, 10 에서도 TRUE (설계 단계 확인). 한두 문장: 한 점에서 맞았다고 모든 입력에서 맞는 것은 아니다, 경계(0, 1, 양 끝 근처)를 격자에 넣어 대조한다(6장 경계 사례와 같은 동작).
- **2.3**: 일상 예(두 줄을 나란히) → 직접 계산(정렬 → $p_k = (k-0.5)/n$ → `qnorm(pk)` → 표준화 → 점과 $y = x$) 과 `qqnorm()`/`qqline()` 을 두 칸에 나란히(이전 판 176–205). 이전 판 주석 "여학생 몸무게" 는 "몸무게"로(C-6). 이어서 손그림 두 장:
  - `figures/qqplot-tail-ex.png`: 파란 곡선이 표본($Q_E$), 빨간 곡선이 정규분포($Q_T$). 오른쪽 꼬리에서 $Q_E < Q_T$ → 점이 직선 **아래**로 → 표본의 오른쪽 꼬리가 얇다.
  - `figures/qqplot-tail-ex2.png`: $Q_E > Q_T$ → 점이 직선 **위**로 → 오른쪽 꼬리가 두껍다.
  - 손그림에는 범례가 없으므로 색의 뜻을 캡션에 적는다. 두 그림 모두 오른쪽 꼬리만 그렸다. **왼쪽 꼬리에서는 반대**(점이 직선 아래면 왼쪽 꼬리가 두껍다)라는 문장을 더한다(C-15). `fig-alt` 를 단다(C-14).
- **2.4**: 네 분포의 Q-Q plot 을 이름을 가리고 2×2 한 그림으로(이전 판 245–351 의 네 청크를 하나로) → 예측 → 답과 함께 같은 순서의 밀도 그림 2×2. t 분포 제목은 `df = 8`(B-5). 모양 규칙 네 줄(양 끝이 직선 안쪽으로 눕는 S자 = 꼬리가 얇다, 바깥으로 = 두껍다, 아래로 볼록 = 오른쪽 치우침, 위로 볼록 = 왼쪽 치우침). 끝에 카이제곱분포와의 Q-Q (`qqplot(qchisq(ppoints(500), df = 3), y)`, 이전 판 358–368) 를 짧게: 정규분포가 아닌 분포와 비교할 때.
- **2.5**: 3×3 lineup 그림(8개는 `rnorm(20)`, 1개는 `rexp(20)`, 시드 고정, 위치는 시드로 정함) → 예측 → 답 공개. 이어서 Shapiro–Wilk 검정의 검정력 표를 시뮬레이션으로(9장 몬테카를로 오차 링크 `09-simulation.html#sec-monte-carlo`): 지수분포에서 뽑은 표본 n = 4, 6, 20, 100 의 기각률(설계 단계 4,000회: 0.12, 0.23, 0.83, 1.00), 정규분포에 가까운 t(30) 에서 n = 20 과 n = 5,000 의 기각률(0.07, 약 0.62~0.66). 해석: 작은 표본에서는 검정이 정규성 위반을 잘 잡지 못하고, 큰 표본에서는 작은 차이도 기각한다. **정규성은 그림과 표본 크기로 판단하고 검정 p값만으로 정하지 않는다**(B-11). 정규성 검정 이름은 한 줄(Shapiro–Wilk, Kolmogorov–Smirnov, Anderson–Darling, 철자 C-2). 끝에 iris 종 × 측정 변수 Q-Q 를 ggplot2 `stat_qq()`·`stat_qq_line()` 과 `facet_grid()` 로(이전 판 388–407, ggpubr·`rownames_to_column` 제거, C-19). 그림 아래 두 문장으로 무엇이 보이는지 쓴다(예: 측정 단위가 0.1 cm 라 점이 계단 모양으로 놓이는 칸이 있다 — 렌더 결과를 보고 확인해서 쓴다).

의도: 대응과 독립을 자료로 구분하고, 계산을 세 경로로 대조한다. 이전 판 노트의 결함 셋(`2*pt(t)` 부호, `sleep` 독립 분석, 신뢰구간 순서)을 예측·버그 찾기 문항으로 쓴다.

내용:

- **3.1**: 모형 $d_i = y_i - x_i$, $\mu_D$, $\sigma_D^2 = \sigma_X^2 + \sigma_Y^2 - 2\rho\sigma_X\sigma_Y$ (기호는 $\hat\sigma_D$ 로 통일, C-4). 이전 판에 **주석으로만 있던 확인 코드**(547–553)를 살려 이 식을 수치로 대조한다. `read_tsv("dataset/DBP.txt")` (경로를 `dataset/` 으로, B-21). 직접 계산 → `t.test(D1)` 대조 → 예측(부호) → 실행: p = 2 → 수정 `2 * pt(-abs(tstat), df)`. 해석 문장: 시험약 군 20명의 1개월 뒤 이완기 혈압은 평균 3.05 mmHg 낮아졌다(t = −7.49, 자유도 19, 95% 신뢰구간과 함께).
- **3.2**: 위약군(B, 결정 5)에 같은 계산 → −1.55 mmHg, p = 0.0012. 4개월 뒤는 A −15.2, B −4.8(p ≈ 3.5×10⁻⁸). 대응 검정이 답하는 질문은 "**이 군 안에서** 변했는가"이고 연구 질문은 "시험약이 위약보다 더 낮추는가"다. 변화량 `DBP5 − DBP1` 을 군끼리 비교하는 독립 이표본 t 검정을 한 청크로 보여 준다(t = −12.15). 계산법은 3.4 에서 다룬다고 적는다.
- **3.3**: 이전 판 코드(1401–1412: `t.test(extra ~ group, data = sleep, var.equal = TRUE)` 와 `summ_t1`)를 **"이전 판 노트의 코드"** 로 밝혀 싣는다 → 예측 → `table(sleep$ID, sleep$group)` (모든 칸 1). 쌍체 분석 두 방법:
  1. 넓힌 표 `pivot_wider(sleep, names_from = group, values_from = extra, names_prefix = "drug")` 뒤 `t.test(drug2, drug1, paired = TRUE)`
  2. `t.test(Pair(drug2, drug1) ~ 1, data = 넓힌표)`
  formula 에 `paired = TRUE` 를 주는 코드는 오류 청크로 실행해 메시지 `cannot use 'paired' in formula method` 를 보인다(R 4.4.0 NEWS: formula 방법이 `paired` 를 막는다). 결과 비교 표: 독립(등분산) t = −1.86, 자유도 18, p = 0.079 / 쌍체 t = 4.06 (약2 − 약1), 자유도 9, p = 0.0028. **결론이 바뀐다.** 환자별로 두 점을 선으로 이은 그림(새 R 청크) → 개인차. 이유: 두 약의 수면 증가의 상관 0.80, 3.1 의 $\sigma_D$ 식. 검정력 모의(개인차 SD 2, 효과 1, n = 10, 4,000회): 독립 분석 0.04, 쌍체 0.50. 마지막으로 **짝은 위치가 아니라 키로 맞춘다**: 행을 섞은 뒤(`set.seed()` 고정) `extra[group == "1"]`, `extra[group == "2"]` 로 나누어 `paired = TRUE` 를 주면 결과가 달라진다(설계 단계에서 시드 없이 섞은 한 번: p = 0.137). `pivot_wider()` 는 `ID` 로 짝을 맞추므로 행 순서와 무관하다(12장의 키). 문장 하나: 내장 함수와 결과가 일치하는 것(계산의 검증)과 자료에 맞는 검정을 골랐는지(설계의 검증)는 다른 확인이다(H-6).
- **3.4**: 모형, 가정 세 줄(정규, 독립, 등분산. 이전 판의 "각 집단 간 평균은 서로 다름" 은 대립가설이므로 뺀다, B-6), 합동분산 식(기호 $s_p$ 로 통일, C-4). 자료는 `glimpse()` 로 보인다(이전 판의 `kbl() |> scroll_box()` 대신). 세 경로:
  1. 이전 판 `indep_t_test()` 를 그대로 실행하고 `t.test(pdi ~ pidyn, data = , var.equal = TRUE)` 와 `all.equal()` 로 원소마다 대조 → `conf.int` 가 다르다(상한, 하한 순서, B-1). 고친 함수(`c(lcl, ucl)`, 기본 인수 `y = y` 제거, `pt(-abs(t))`).
  2. `t.test()`: 평균 차이 = Control − Dysmenorrhea = 1.116, t = 2.688, p = 0.0100.
  3. `lm(pdi ~ pidyn)`: 계수 −1.116, t = −2.688. **부호가 반대인 이유**: `t.test()` 는 첫 수준 − 둘째 수준, `lm()` 의 계수는 둘째 수준 − 기준 수준(첫 수준). `model.matrix(~ pidyn)` 의 앞 몇 행으로 설계행렬이 절편 열(1)과 0/1 열임을 보이고, 8장 정규방정식(`08-algorithms.html#sec-nr-regression`)의 $\mathbf{X}$ 와 같은 모양이라고 연결한다. 이전 판 콜아웃(421–431)의 $y_i = \beta_0 + \beta_1 x_i + \epsilon_i$, $x_i \in \{0, 1\}$ 을 여기로 옮긴다.
  상자그림과 점(이전 판 710). Welch 와 `var.equal` 은 한 단락으로 9장 `#sec-assumption` 을 가리키고 되풀이하지 않는다. 해석 문장: 월경통 군의 PDI 평균이 대조군보다 1.12 mm 작았다(95% 신뢰구간 0.28~1.95, p = 0.010).
- **3.5**: `str(res)` 와 원소 표(`statistic`, `parameter`, `p.value`, `conf.int`(길이 2, 속성 `conf.level`), `estimate`, `stderr`, `method`). 이전 판의 "결과에 대응하는 수치들이 저장되지는 않음"(B-20)을 고쳐 "결과는 이름 붙은 리스트로 저장되며 원소 이름이 함수마다 다르다"로 쓴다. `t.test()` 인수 표(x, y, alternative, mu, paired, var.equal, conf.level), 오탈자 `parametmer` 정정. 7절 broom 을 예고한다.

### 3.4 절 4: 셋 이상 집단: 분산분석의 원리 `{#sec-oneway-anova}` (약 360줄)

의도: 왜 쌍별 t 검정을 되풀이하지 않는지 시뮬레이션으로 확인하고, 변동분해와 F 를 손으로 계산해 `anova()` 와 대조한다.

내용:

- **4.1**: 일상 예(20면 주사위) → 이전 판 서술(717–726)을 고쳐 쓴다: 세 집단 쌍은 ${}_3\mathrm{C}_2 = 3$, "귀무가설이 참일 때 기각하지 않을 확률 0.95", $1 - 0.95^3 = 0.143$ 은 세 검정이 **독립일 때**의 값(B-7). 예측 → 시뮬레이션(각 20명, 세 집단, 5,000회 이상, 시드 고정): 세 쌍 중 하나 이상 기각 ≈ 0.12, 같은 자료의 F 검정 기각률 ≈ 0.05 (설계 단계: 0.115, 0.046 / 감사 20,000회: 0.1196, 0.0488). 몬테카를로 표준오차를 함께 출력한다. 해석: 쌍별 검정은 집단을 공유해 독립이 아니므로 0.143 보다 작지만 0.05 보다 크다. F 검정 한 번으로 "모두 같다"를 검정하고, 어느 쌍이 다른지는 5절의 사후검정이 맡는다.
- **4.2**: 일상 예(세 반 점수) → 가정 세 줄, 모형 $y_{ij} = \mu + \alpha_i + \epsilon_{ij}$, 첨자 정의($i$ 는 집단, $j$ 는 집단 안 관측, C-4). 제약은 $\sum_i n_i \alpha_i = 0$ 으로 쓰고 균형 설계에서 $\sum \alpha_i = 0$ 이 된다고 적는다(C-5, 예제 coagulation 이 불균형). 가설 두 형태. 효과 α 그림은 이전 판 766–808 을 살리되 `set.seed()` 를 주고, $\mu$ 글자는 `geom_text(aes(...))` 대신 `annotate()` 로(B-19, ggplot2 4.0.3 의 길이 1 경고), `ggpubr::theme_pubclean()` 대신 ggplot2 기본 테마.
- **4.3**: 세 편차(전체·집단 간·집단 안). 편차 분해 그림(새 R 청크): α 그림의 자료로 한 관측의 전체 편차가 집단 간 편차와 집단 안 편차 두 조각으로 나뉘는 것을 화살표로. 식 SST, SSB, **SSW $= \sum_i (n_i - 1) s_i^2$** (A-2 수정, 이전 판 856 의 $\sum_{i=1}^{n_i}$ → $\sum_{j=1}^{n_i}$, C-4). 예측 → coagulation 으로 손계산: 바른 식 112, 이전 판 식 132.99, `anova()` 112, 항등식 340 = 228 + 112 성립, 이전 판 식이면 228 + 132.99 = 360.99 ≠ 340. 한 문장: 식을 수치로 대조하면 식의 오류가 드러난다.
- **4.4**: 자유도(N − 1, g − 1, N − g. 이전 판의 "총관측수 − 전체평균" 표현은 쓰지 않는다, C-4), MSB 와 MSW, F 분포, 분산분석 표. **균형 설계에서 MSB = n × (집단 평균들의 분산)** (B-9): Case 1(시드 123)에서 `var(집단 평균)` 0.0089, × 20 = 0.178 = MSB. MSW 는 σ² 의 추정. p값은 `pf(F, df1, df2, lower.tail = FALSE)` (C-16). 이전 판의 SSE·SSW 혼용은 SSW 로 통일.
- **4.5**: 이전 판 `plot_anova_sim()`(954–1020)을 세 함수로 나눈다(C-17): 자료 생성 `sim_anova_data(n, mvec, sigma)`, 표 계산 `anova_table(y, group)`, 그림 `plot_anova_data(...)`. 계산 함수는 먼저 `anova(lm(y ~ group))` 과 `all.equal()` 로 대조한다. 네 경우(n = 20, `set.seed(123)` 그대로):

| 경우 | 모평균 | σ | F | p | MSW |
|---|---|---|---:|---:|---:|
| 1 | (0, 0, 0) | 1 | 0.21 | 0.81 | 0.85 |
| 2 | (−5, 0, 5) | 1 | 592.6 | < 0.001 | 0.85 |
| 3-a | (−1, 0, 1) | 1 | 24.7 | < 0.001 | 0.85 |
| 3-b | (−1, 0, 1) | 3 | 3.17 | 0.0495 | 7.66 |

  3-b 는 이전 판 캡션이 $\sigma^2 = 3$ 이었지만 코드는 `sd = 3` 이라 $\sigma^2 = 9$ 다(B-10). 예측 "MSW 는 어느 값 근처?" 의 답이 9 근처(7.66)인 것을 이 차이로 설명한다. 그림은 Case 3-a 와 3-b 를 나란히 하나로 싣고, 나머지는 표로만 둔다(분량).
- **4.6**: 이전 판 콜아웃의 6×4 행렬(442–473)을 예측 문항으로 → `qr(X)$rank` 가 3 이라 β 네 개를 정할 수 없다(B-8). `model.matrix(~ diet, data = coagulation)` 의 대표 네 행(집단마다 한 행)으로 R 이 쓰는 설계행렬(절편 + 가변수 g − 1 개)을 보인다. `coef(lm(coag ~ diet))`: 절편 61 = A 평균, `dietB` 5 = B − A. 8장 `#sec-nr-regression` 의 정규방정식이 이 $\mathbf{X}$ 로 계수를 구한다. t 검정(3.4)과 분산분석이 같은 틀이라는 한 문단. formula 연산자 전체는 다루지 않는다(4절 대응표).

의도: 실제 자료 하나로 탐색 → 가정 확인 → F 검정 → 사후검정 → 해석 문장까지 한 번 끝낸다. 이전 판에 없던 해석 문장을 출력마다 붙인다(C-18, H-7).

| 소절 | ID | PRIMM | 자료 | 줄 |
|---|---|---|---|---:|
| coagulation 자료 | `{#sec-coagulation}` | 상자그림만 보고 평균이 다른 먹이 쌍을 골라 보라 (5.4 에서 대조) | `coagulation` [이전 판] | 40 |

| F 검정 결과 읽기 | `{#sec-anova-result}` | F = 13.57, 자유도 (3, 20), p = 4.7×10⁻⁵ 를 한 문장으로 쓰면? | `lm`, `aov` | 35 |

내용:

- **5.1**: "동물 24마리"(이전 판 "쥐", `?coagulation` 은 animals, C-7). 넓은 표는 `mutate(번호 = row_number(), .by = diet) |> pivot_wider(names_from = diet, values_from = coag)` 로(이전 판의 `c(1:4, 1:6, 1:6, 1:8)` 하드코딩 대신, C-8). 집단 크기 4, 6, 6, 8 불균형을 짚는다. 상자그림 + 점(이전 판 1109–1112), 집단별 평균(61, 66, 68, 61)과 SD.
- **5.2**: 예측 → 2.5 의 검정력 표(n = 4 에서 지수분포도 약 12% 만 기각)를 가리켜 "기각하지 않았다"는 "정규성을 확인했다"가 아니라고 쓴다(B-11). 모형 잔차 24개를 하나로 보는 Q-Q 와, 2.5 와 같은 방식의 lineup(잔차 Q-Q 를 정규분포에서 뽑은 24개짜리 8개 사이에). 잔차 Shapiro p = 0.863 은 보조로만. 등분산: 집단 SD 의 최대/최소 비(2.83 / 1.67 ≈ 1.7), `car::leveneTest()` 의 **기본값은 `center = median`**(Brown–Forsythe 변형, p = 0.593)이고 평균을 쓰면 p = 0.560 (B-12; 이전 판 주석 "SPSS" 는 옮기지 않는다). `fligner.test()` 한 줄. 등분산이 의심될 때의 `oneway.test()`(Welch 분산분석) 한 줄과 9장 `#sec-assumption` 링크.
- **5.3**: `anova(lm(coag ~ diet))` 와 `summary(aov(coag ~ diet, data = coagulation))` (C-20: `aov()` 에 `lm` 객체를 넘기지 않는다). 해석 문장 예: "네 먹이의 평균 응고 시간이 모두 같다는 가설을 기각한다(F = 13.57, 자유도 3과 20, p < 0.001). 이 검정은 어느 먹이가 다른지는 말하지 않는다." 효과 크기 $\eta^2 = SSB/SST = 228/340 = 0.67$ 한 줄.
- **5.4**: `TukeyHSD(aov(...))` 표와 그림(이전 판 1143). 결과: B−A(5, p = 0.018), C−A(7, p < 0.001), D−B(−5, p = 0.004), D−C(−7, p < 0.001) 는 신뢰구간이 0 을 포함하지 않고, D−A(0), C−B(2, p = 0.48) 는 포함한다. 해석: A 와 D, B 와 C 가 각각 비슷하고 두 묶음 사이에 차이가 있다. 5.1 의 예측과 대조. 이전 판 콜아웃의 "F 검정 결과 … 다르다는 결론을 얻은 경우" 는 Tukey HSD 의 전제가 아니므로 쓰지 않는다(B-13). `tidy(TukeyHSD(...))` 는 7.1 에서 다시 쓴다. emmeans 는 쓰지 않는다(같은 결과, 패키지 하나 감소).
- **5.5**: `pairwise.t.test(..., p.adjust.method = "none")` 과 `"bonferroni"` 결과를 나란히(C−B: 0.159 → 0.953). 예측 → 임계값 표(g = 4, 잔차 자유도 20, 비교 6쌍, t 척도):

| 방법 | 임계값 | 계산 |
|---|---:|---|
| Scheffé | 3.049 | `sqrt(3 * qf(0.95, 3, 20))` |
| Bonferroni | 2.927 | `qt(1 - 0.05 / 12, 20)` |
| Tukey | 2.799 | `qtukey(0.95, 4, 20) / sqrt(2)` |
| 보정 없음 | 2.086 | `qt(0.975, 20)` |

  임계값이 클수록 보수적이다. 모든 쌍 비교에서는 **Scheffé 가 가장 보수적**이고 이전 판의 순서는 틀렸다(B-13). 가족오류율 시뮬레이션(균형 n = 6, g = 4, 귀무가설 하, 5,000회, 감사 값): Tukey ≈ 0.053, Bonferroni ≈ 0.040, 보정 없음 ≈ 0.19. Tukey 는 균형 설계에서 명목 수준을 맞추므로 "매우 보수적"이 아니다. Duncan 은 R 기본에 없어 다루지 않는다는 한 줄(결정 6). 표기 Scheffé.

### `dataset/ch14/sleep-drug.csv`

- **출처와 성격**: R `datasets::sleep` (Cushny & Peebles, 1905 의 수면제 자료, Student 1908 이 인용)의 값을 **그대로** 쓰고, 열 이름을 한국어로 바꾸고, 약 B 행의 순서를 섞은 파일이다. 값은 실제 자료이고 **행 순서(약 B 의 기록 순서)는 가상**이라고 README 와 노트에 밝힌다.
- **생성 스크립트**: `dataset/ch14/make-ch14-data.R`. `write.csv(row.names = FALSE, fileEncoding = "UTF-8")` 로 써서 12장 파일처럼 문자열과 머리글에 큰따옴표가 붙게 한다.
- **열**:

| 열 | 유형 | 값 |
|---|---|---|
| `환자번호` | 문자 | `"P01"` ~ `"P10"` (`sleep$ID` 1~10) |
| `약` | 문자 | `"A"` (`group` 1), `"B"` (`group` 2) |
| `수면증가` | 실수 | `sleep$extra` (평소보다 늘어난 수면 시간, 시간 단위, 소수 한 자리) |

- **행**: 20행. 2~11행은 약 A, 환자번호 P01~P10 순서. 12~21행은 약 B 를 **`set.seed(2026); o <- sample(10)`** 의 순서로: P09, P01, P06, P05, P03, P04, P07, P10, P08, P02. 앞 5줄은 다음과 같아야 한다(8절 프롬프트에 그대로 붙인다).

```
"환자번호","약","수면증가"
"P01","A",0.7
"P02","A",-1.6
"P03","A",-0.2
"P04","A",-1.2
```

- **심어 둔 함정과 가르치는 것**:
  1. 같은 환자 10명이 두 약을 모두 먹었다(대응). 그런데 앞 5줄에는 약 A 만 보여 환자번호가 반복된다는 사실이 드러나지 않는다 → **자료 구조는 앞 몇 줄이 아니라 `count(환자번호)` 로 확인한다**(1.1, 1.3).
  2. 약 B 행이 환자번호 순서가 아니다 → `수면증가[약 == "A"]` 와 `수면증가[약 == "B"]` 를 위치로 짝 지어 `paired = TRUE` 를 주면 **다른 환자끼리 짝이 지어지고 오류도 경고도 없다** → **짝은 키(환자번호)로 맞춘다**(3.3, 12장의 키).
- **정답 값** (원문 대조용, 설계 단계에서 계산):

| 항목 | 값 |
|---|---|
| 행 수 / 환자 수 / 환자당 행 | 20 / 10 / 2 |

| 약 B 합계, 평균 | 23.3, 2.33 |

| 파일 순서대로 위치로 짝 지은 쌍체 t 검정 (A − B) | t = −2.095, 자유도 9, p = 0.0657 |
| 독립 이표본 (등분산) | t = −1.861, 자유도 18, p = 0.0792 |
| 독립 이표본 (Welch) | 자유도 17.78, p = 0.0794 |
| 부호순위 검정 (짝 맞춤, 참고) | p ≈ 0.0039 (동점 경고) |

## 6. "AI와 함께" 절 설계

ID `{#sec-ai-basic-stat}`. 응답은 4단계에서 `student-ai` 워커가 **한 번** 만든다. 기록은 `ai-transcripts/14-basic-stat-analysis/sleep-drug-test.md` (머리: 모델, 날짜, 호출 방법, 프롬프트 전문, 응답 전문. 형식은 `ai-transcripts/12-data-handling/sido-loans-per-capita.md`). 호출 지시문은 9·11·12장과 같다. 노트의 "흔한 오류"와 "AI 가 보지 못한 부분" 표에는 **실제 응답에서 확인된 것만** 싣는다. 아래 6.4 는 예상일 뿐이다.

### 6.1 이 절의 목표 (노트의 `callout-important`)

AI 에게 두 약의 효과를 비교하는 검정을 요청하고, AI 가 고른 검정이 자료 구조에 맞는지, 생성된 코드가 짝을 올바르게 맞추는지 1절의 표와 3.3 의 확인으로 검증한다.

### 6.2 과제 명세 (학생이 받는 과제문)

> `dataset/ch14/sleep-drug.csv` 는 수면제 두 종류(A, B)를 먹었을 때 평소보다 늘어난 수면 시간을 기록한 자료다. 두 약의 효과에 차이가 있는지 검정하라. AI 를 써도 좋다. 제출물: (1) AI 에 보낸 프롬프트와 받은 응답, (2) 생성 코드를 실행한 결과, (3) 검증 기록(자료 구조 확인, 짝 확인, 다른 경로와의 대조), (4) 최종 결론 두세 문장(효과의 방향과 크기, 신뢰구간, p값).

### 6.3 학생 프롬프트 전문 (`student-ai` 에 그대로 보낸다)

```text
수면제 두 종류의 효과를 비교하는 과제를 하고 있어. 파일은 sleep-drug.csv 하나고, 앞부분은 이렇게 생겼어.

"환자번호","약","수면증가"
"P01","A",0.7
"P02","A",-1.6
"P03","A",-0.2
"P04","A",-1.2

전체 20행이야. 약은 A 또는 B이고, 수면증가는 약을 먹었을 때 평소보다 늘어난 수면 시간(시간 단위)이야.

약 A와 약 B의 효과에 차이가 있는지 R로 검정하는 코드를 짜 주고, 결과를 어떻게 해석하면 되는지도 알려 줘.
```

- 쓰지 않은 것: "같은 환자", "쌍체", "대응", "환자 10명". 학생이 앞 5줄만 복사했다는 설정이다(12장과 같은 방식). 붙인 5줄은 5절 파일에서 그대로 가져온 것이어야 한다(생성 뒤 `head -5` 로 확인).

### 6.4 검증 항목 (8.3 의 단계)

1. **자료 구조**: `count(dat, 환자번호)` 와 `table(dat$환자번호, dat$약)` → 10명이 두 약을 모두 먹었다. 1.3 표에서 검정을 다시 고르고 AI 의 선택과 비교한다.
2. **그대로 실행**: R 4.6.1 에서 오류·경고가 있는지. formula 에 `paired = TRUE` 를 주었다면 `cannot use 'paired' in formula method`. `getRversion()` 을 기록한다.
3. **짝의 근거**: 쌍체를 골랐다면 무엇으로 짝을 지었는가. 파일 순서대로 나누었다면 B 행이 기록 순서라 다른 환자끼리 짝이 된다(p = 0.066). `pivot_wider(names_from = 약, values_from = 수면증가)` 로 환자번호에 맞춘 결과(t = 4.06, 자유도 9, p = 0.0028)와 대조하고, **행을 섞어도 결과가 같은지** 확인한다(불변량).
4. **세 경로 대조**: `t.test(B, A, paired = TRUE)`, 차이의 일표본 `t.test(d)`, `lm(d ~ 1)` 의 t·p 가 같은지. 독립 검정 결과(p = 0.079)와 나란히 놓고 결론이 바뀌는지.
5. **해석과 가정 확인**: 차이의 방향(B − A 인가 A − B 인가)과 단위, 신뢰구간을 말했는지, "유의하지 않으므로 효과가 없다" 류 문장이 있는지. 정규성을 각 약 집단에 확인했는지 차이에 확인했는지(쌍체에서는 차이), n = 10 의 Shapiro 결과를 어떻게 읽었는지(2.5 의 검정력 표), 쌍체 분석에 등분산 검정을 붙였는지.

## 9. 강사 확인 항목 (2단계 설계)

`basic-stat-analysis-decisions.md` 의 "강사 확인 항목" 아래 "2단계 설계"로 옮겼다.

1. **절 구성**: 감사 H-1 의 독립 절 "검정은 선형모형이다"를 두지 않고 3.4(t 검정 = 회귀)와 4.6(분산분석 = 회귀)으로 나눴다. 범주형과 상관은 6절, 결과 정리는 7절. **가정**: 내용 7절 + AI + 연습문제의 9절 구성.
2. **다른 장 참조 방식**: 단독 렌더에서는 다른 파일의 `@sec-` 가 풀리지 않는다(12장은 평문 "11장에서"만 썼다). **가정**: `[9장 '1종 오류와 p-값의 분포'](09-simulation.html#sec-type1-error)` 처럼 장 이름을 적은 상대 링크. `docs/preview/` 에서 동작하고, 책 전환 때 `@sec-` 로 바꾼다.
3. **범주형 예제**: 이전 판에 예제가 없어 새로 들인다. **가정**: χ² 는 12장의 `titanic3.csv`(객실 등급 × 생존), Fisher 는 `?fisher.test` 의 차 맛보기 표(Fisher 1935), 상관은 `anscombe` 와 8장의 `mtcars` `mpg ~ wt`.
4. **정규성 확인 방법**: 집단별 Shapiro 검정 대신 잔차 Q-Q 와 lineup 을 본문 방법으로 두고, 검정 p값은 표본 크기(검정력 표)와 함께 읽게 한다. **가정**: 이대로.

**규칙**

- 다른 장 참조는 상대 링크(9절 강사 확인 2). `@sec-` 는 같은 파일 안의 ID 에만 쓴다. 확인한 대상 앵커: 9장 `sec-ci-meaning`(733), `sec-type1-error`(803), `sec-power`(851), `sec-assumption`(887), `sec-monte-carlo`(175), `sec-clt`(652) / 8장 `sec-nr-regression`(1765), `sec-nr-logistic`(1848) / 12장 `sec-reframe`(1356), `sec-summarise-by`(992). 모두 존재한다.
